## 2. How does it works
### Introduction & log-in
Wow, you made it ! You managed to reach the [feedback portal](https://www.youtube.com/watch?v=xvFZjo5PgG0) !

> *Some questions :* 
- What is the feedback portal ?
    - It's the website used to manage the feedback for every applicants in SCRTH.
- How do I use it ?
    - Bro be patient I didn't even explained everything.
 
Once you arrive on the website, you should get the **log-in card**.
It's like 99% of the websites in the world, you put your usernames and passwords *(that have been given internally)* and then, magic, you're now logged-in!

> [!NOTE]
> There has been some issues when logging-in, here is some error codes that shown up.
> 
> `Username and password are required` : This mean that you've entered only the username or the password
> 
> `Invalid credentials` : Your password or username is wrong
> 
> `Could not reach server` : Unknown issue, you must report that to the ID


### 2b. Adding a feedback for a specified user
<img width="1061" height="972" alt="image" src="https://github.com/user-attachments/assets/0e9e1030-44aa-41d4-8b82-50f39e1376a4" />
All of the fields that have a colored square around them are the things that you'll be using for the feedback. Those without color are useless for now.

> - **Blue** : The discord ID of the username example : `843009938661048331`
> 
> - **Orange** : The title example: `September 2026 TSG application feedback`
> 
> - **Yellow** : The main place where you'll enter the feedback. You MUST follow the feedback prompt[^2].
>
> - **Green** : The footer, this is where you'll put the number of embeds, example : `1/2`
>
> - **White** : This is used to remove or add fields, with the inline disabled (by default) or enabled[^3].
> 
> - **Pink** : Where you'll put the color in hexadecimal.

> [!IMPORTANT]
> You'll only use 2 colors:
> 
> `#ff0000` for failed applications
> 
> `#00ff34` for passed applications

## 3. Managing feedback for multiple users

> - **White** : All of the users that currently have feedback.
>
> - **Green** : Numbers of feedback per users.
>
> - **Dark green** : The user who you're watching feedback.
>
> - **Purple** : Title of the embed.
>
> - **Beige/maroon** : x/x feedback.
>
> - **Dark blue** : the "description" field.
>
> - **Yellow** : Arrows to change feedback to x -> x.
>
> - **Pink** : Buttons to edit the selected feedback.
>
> - **Light blue** : Delete feedback button
